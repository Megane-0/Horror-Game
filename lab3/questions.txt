How can you get all four blades to rotate with just one time-dependent rotation matrix?
- We set different initial positions for each blade, then rotate all round the same point using the same matrix

- the wing rotation matrix also includes the movement of the body, which is done afterwards

How did you handle the camera matrix for the skybox?
- We zeroed out the translation components when drawing the skybox

How did you represent the objects? Is this a good way to manage a scene or would you do it differently for a "real" application?
- We modified the model-to-world matrix for each drawn model. In a real application one would like to do it all once before display is called.

What special considerations are needed when rendering a skybox?
- Turn of z buffering and have the camera inside it. It should rotate with the camera but not translate.
